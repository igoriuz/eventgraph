Dateiformat für Event-Modelle

Wie sollen die Knoten und Kanten definiert werden?

A

YAML (human-friendly)

context: payments
nodes:
  - id: place-order
    type: command
    label: Place Order
    data:
      fields: [orderId, customerId, items, total]

  - id: order-placed
    type: event
    label: Order Placed
    data:
      fields: [orderId, customerId, items, total, placedAt]

  - id: order-summary
    type: read-model
    label: Order Summary
    data:
      fields: [orderId, status, total, items]

edges:
  - from: place-order
    to: order-placed
    type: produces

  - from: order-placed
    to: order-summary
    type: projects-to

Pros

  • Gut lesbar, leicht manuell editierbar
  • Git-Diffs sind sauber
  • Vertraut für DevOps/Config-Welt

Cons

  • Indentation-sensitiv
  • Kein Schema-Support in Editoren ohne Extra-Config
B

JSON Schema (machine-friendly)

{
  "context": "payments",
  "nodes": [
    {
      "id": "place-order",
      "type": "command",
      "label": "Place Order",
      "data": {
        "fields": ["orderId", "customerId", "items", "total"]
      }
    },
    {
      "id": "order-placed",
      "type": "event",
      "label": "Order Placed"
    }
  ],
  "edges": [
    { "from": "place-order", "to": "order-placed", "type": "produces" }
  ]
}

Pros

  • JSON Schema = volle Editor-Autocompletion
  • Trivial für Agenten zu parsen/generieren
  • Kein Indentation-Problem

Cons

  • Verbose, mehr Noise in Diffs
  • Weniger angenehm manuell zu editieren
C

YAML mit JSON Schema Validierung

# eventgraph.schema.json liegt im Paket
# Editor-Support via YAML Language Server + Schema-Mapping

context: payments

nodes:
  - id: place-order
    type: command
    label: Place Order
    data:
      fields: [orderId, customerId, items, total]

edges:
  - from: place-order
    to: order-placed
    type: produces

Pros

  • Best of both: lesbar + validiert
  • JSON Schema für Autocompletion in VS Code
  • YAML für saubere Diffs und Editierbarkeit

Cons

  • YAML-zu-JSON-Schema-Mapping braucht Setup
  • Etwas mehr Tooling-Aufwand initial
